The configured backend origin needs host access before scans can reach it. Click Save to grant it.

Privacy & security

  • The extension only sends URLs to your backend (POST /api/analyze) — it never fetches or opens the URLs being analyzed.
  • No Google Safe Browsing API key (or any secret) is stored in the extension; threat lookups happen server-side.
  • Host permissions are minimal: the default backend origin is required, any other backend origin is optional and requested only when you save it.
